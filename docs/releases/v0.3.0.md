# DPWIM v0.3.0

DPWIM v0.3.0 expands the Windows input mixer with causal sync handling,
per-source pitch controls, immediate global bypass, clearer latency reporting,
and real-time level meters.

## Highlights

- Keep negative source offsets causal by automatically delaying the other
  active paths only as much as required.
- Distinguish Base, OUT, and automatic SYNC latency and report the final sample
  count to the host.
- Adjust per-source Transpose and Fine Pitch from the Advanced panel.
- Bypass DPWIM processing and captured sources immediately at unity with zero
  reported plugin latency.
- Monitor post-gain Dry Input and source contributions with horizontal L/R
  meters, plus the final summed output with a dedicated vertical MAIN OUT
  meter.
- Check for a newer GitHub release without automatically downloading or
  replacing plugin files.
- Preserve the existing `targetLatency` parameter ID and legacy project/state
  compatibility while appending the new bypass parameter.

## Preview status

This is an unsigned Windows public preview. The release is locally verified
with deterministic processor tests, a live Windows process-loopback test,
hosted VST2/VST3 probes, state restoration, and responsive editor snapshots.
It is not yet validated across a broad DAW matrix and is not claimed
production-ready.
