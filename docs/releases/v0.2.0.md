# DPWIM v0.2.0

`v0.2.0` adds the owner-selected native mixer-console interface to DirectPipe
Windows Input Mixer while preserving the verified `v0.1.0` audio and state
contracts.

## Highlights

- Compare Dry Input and four application/desktop sources in one mixer view.
- Adjust every source independently from -60 to +12 dB.
- Apply per-source -200 to +200 ms manual sync trims.
- Identify selected applications with their real Windows executable icons.
- Resize the editor from 840 x 520 through 1280 x 800.
- Refresh and distinguish duplicate process names without changing persisted
  executable identities.
