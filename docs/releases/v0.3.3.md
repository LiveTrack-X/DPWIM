# DPWIM v0.3.3

DPWIM v0.3.3 is a captured-source stability maintenance release for the
Windows VST2/VST3 input mixer.

## Highlights

- Reserve at least 20 ms on the common timeline while any Windows capture
  source is active. At 48 kHz this is 960 samples.
- Keep the no-source minimum unchanged at 10 ms / 480 samples.
- Align Dry Input, captured sources, footer OUT/SYNC values, and host PDC to
  the same effective reserve.
- Add a deterministic late-packet regression covering three consecutive
  256-frame host callbacks without new capture delivery.
- Preserve all parameter IDs, saved-state compatibility, VST identities,
  source processing, and internal/host bypass contracts.

## Validation

- Clean Windows x64 Release build completed in `out/build-v0.3.3`; VST2 and
  VST3 file/product versions report `0.3.3`.
- All 3 registered CTest targets passed, including the late-packet regression.
- Live Windows process loopback captured 66,240 frames with non-zero energy.
- Loaded and extracted-package VST2/VST3 probes passed scan, instantiate,
  latency, processing, bypass, and state checks.
- Reference, minimum, Advanced, and bypass editor contracts passed.
- Release ZIP hashes matched `SHA256SUMS-v0.3.3.txt`.
