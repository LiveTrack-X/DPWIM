# DPWIM v0.3.4

DPWIM v0.3.4 is a captured-source continuity maintenance release for the
Windows VST2/VST3 input mixer.

## Highlights

- Keep valid queued application audio when WASAPI reports a timestamp
  discontinuity.
- Keep the current flagged packet usable and record the event through a
  diagnostic counter.
- Continue to re-prime on actual FIFO underrun, overwrite, explicit source
  changes, and audio-path resets.
- Add a deterministic regression that primes a captured source, injects a
  flagged packet, and requires the following 512-frame callback to remain
  audible.
- Preserve parameter IDs, saved-state compatibility, VST identities, latency,
  source processing, and internal/host bypass contracts.

## Validation

- Clean Windows x64 Release build completed in `out/build-v0.3.4`; VST2 and
  VST3 file/product versions report `0.3.4`.
- All 3 registered CTest targets passed, including the flagged-packet
  continuity regression.
- Live Windows process loopback captured 67,680 frames with non-zero energy.
- Loaded and extracted-package VST2/VST3 probes passed scan, instantiate,
  latency, processing, bypass, and state checks.
- The minimum-size editor snapshot retained the version, meters, controls, and
  footer without clipping.
- Release ZIP hashes matched `SHA256SUMS-v0.3.4.txt`.
