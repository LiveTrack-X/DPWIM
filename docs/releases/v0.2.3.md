# DPWIM v0.2.3

DPWIM v0.2.3 adds an independent Dry Input ON/OFF control.

## Highlights

- Disable only the upstream microphone or host-chain input while application
  and desktop capture sources continue mixing.
- Preserve the common target-latency path while Dry Input is disabled.
- Automate and restore the Dry Input state through the host project or preset.
- Keep the selected applications, source ON/OFF controls, per-source gains,
  sync offsets, and refreshed Windows application icons from v0.2.2.

## Preview status

This is an unsigned Windows public preview. The release is locally verified
with processor tests, a Windows loopback smoke test, hosted VST2/VST3 probes,
and editor snapshots. It is not yet validated across a broad DAW matrix and is
not claimed production-ready.
