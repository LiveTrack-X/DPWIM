# DPWIM v0.3.1

DPWIM v0.3.1 is a latency, bypass, and meter-responsiveness maintenance
release for the Windows VST2/VST3 input mixer.

## Highlights

- Refresh Dry, source, and MAIN OUT meters at 60 Hz while keeping heavier
  control/status work at 5 Hz.
- Keep DPWIM's persistent internal bypass separate from the host's standard
  bypass so graph reconnection cannot inherit a temporary zero-latency report.
- Align standard host-bypass audio with the unchanged OUT latency while
  retaining immediate, zero-latency behavior for the DPWIM BYPASS button.
- Update host latency immediately for Base Latency, Sync Offset, pitch, source
  enable, and internal bypass changes.
- Reject stale delay history after internal bypass or callback gaps and keep
  continuous Dry audio across normal/standard-host-bypass transitions.
- Cover the complete Base/negative-Offset/pitch timeline at low sample rates
  and invalidate source FIFO history without a UI/audio-thread data race.
- Clarify that OUT is DPWIM's reported plugin delay rather than measured
  end-to-end host or device latency.

## Preview status

This is an unsigned Windows public preview. The release is locally verified
with deterministic processor tests, a live Windows process-loopback test,
loaded VST2/VST3 probes, package extraction and rescan, state restoration, and
responsive editor snapshots. It is not yet validated across a broad DAW
matrix and is not claimed production-ready.
