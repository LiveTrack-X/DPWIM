# DPWIM v0.2.2

`v0.2.2` adds persistent per-source ON/OFF controls and neutral defaults for
new DirectPipe Windows Input Mixer instances.

## Highlights

- Start new instances at the minimum 10 ms Target Latency.
- Start all four source gains at 0 dB.
- Turn every configured source ON or OFF independently.
- Preserve application/desktop identity, gain, and sync offset while OFF.
- Save and restore the source enable state with the host project.
- Refresh Windows executable icons immediately after selecting an application.
- Keep the `v0.2.1` icon/text spacing fix at reference and minimum editor sizes.

Existing host projects and presets continue to restore their saved latency and
gain values instead of being overwritten by the new defaults.
