# DPWIM v0.1.0

`v0.1.0` is the first public preview of DirectPipe Windows Input Mixer.

## Highlights

- Mix upstream microphone/chain audio with Windows application audio.
- Select up to four application or desktop sources.
- Adjust every source independently from -60 to +12 dB.
- Align sources to one target timeline with per-source -200 to +200 ms trims.
- Capture an application process tree or the desktop while excluding the host
  process tree.
- Restore parameters and executable identities with the host project.

## Preview limitations

- The binaries are unsigned and Windows may show a publisher warning.
- DirectPipe and representative third-party DAW manual UI, desktop exclusion,
  unload/reload, and listening tests remain pending.
- No stable, production-ready, or broad DAW compatibility claim is made.
