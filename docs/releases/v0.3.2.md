# DPWIM v0.3.2

DPWIM v0.3.2 is a FIFO discontinuity, oversized-callback, and PDC-ordering
maintenance release for the Windows VST2/VST3 input mixer.

## Highlights

- Include drift and interpolation headroom in the active-source host-block
  safety floor. A 512-frame callback now reserves 514 samples.
- Publish oversized-callback observations atomically from the audio thread.
  Captured sources remain muted and re-prime until the message thread notifies
  the host and the next callback adopts the new floor.
- Invalidate stale FIFO history after underrun, overflow, explicit discard, or
  WASAPI data discontinuity. A generation change anywhere during rendering
  rejects the complete captured-source block.
- Keep the producer frame counter monotonic when capture history is discarded,
  avoiding a producer/consumer race with an active capture callback.
- Serialize update-check result publication with shutdown.
